# Category images

Add one image per site category here. The admin panel (Admin → Categories) lets you set the image path for each category.

Suggested filenames (match paths in `data/categories.json` or as set in Admin):

- `ration.png` → path: `/img/categories/ration.png`
- `food-restaurant.png` → `/img/categories/food-restaurant.png`
- `corrugated.png` → `/img/categories/corrugated.png`
- `cartons.png` → `/img/categories/cartons.png`

Use PNG or JPG. If a file is missing, the site falls back to the logo.
