# Feature product brand logos

Place **logo images only** here (one per brand). The app uses them as follows:

- **Box color** is set per brand (DHL red, FedEx purple, TCS white, UPS brown, Leopards yellow).
- **Logo** is drawn centered on the **front**, **back**, and **top** panels of the 3D box.

Files expected:

- `DHL.png` – DHL logo
- `FEDEX.png` – FedEx logo
- `TCS.png` – TCS logo
- `UPS.png` – UPS logo
- `Leopards.png` – Leopards logo

Use a transparent or white-background logo so it fits the colored box. If a file is missing, the box still shows the solid brand color.
